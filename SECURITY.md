# Sicherheit / Security

**Sicherheitslücke gefunden?** Bitte nicht öffentlich als Issue melden, sondern per E-Mail an info@nue-agentur.de (Betreff „Sicherheit“) oder per Direktnachricht an @ls.terminal auf Instagram.

Richtlinie mit allen Zusagen (Eingangsbestätigung innerhalb von 3 Werktagen, Einschätzung innerhalb von 10 Werktagen, Veröffentlichung frühestens nach dem Update, höchstens 90 Tage): https://ls-terminal.nue-agentur.de/sicherheit.html

**Unterstützte Versionen:** nur die jeweils neueste. LS-Terminal aktualisiert sich selbst.

---

**Found a vulnerability?** Please do not open a public issue. Email info@nue-agentur.de (subject "Security") or send a direct message to @ls.terminal on Instagram. Policy (German): https://ls-terminal.nue-agentur.de/sicherheit.html. Only the latest version is supported; LS-Terminal updates itself.
